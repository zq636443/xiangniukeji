# 外部补录订单台账设计

## 1. 目标

当抖音、美团、闲鱼、线下等业务还没有完全接入平台自动下单链路时，门店和总部需要先把已经真实发生的订单补录进系统，用于完成以下事情：

- 跟踪每一笔外部订单当前在哪个门店、绑定了哪些资产。
- 让资产进入真实的占用状态，避免重复出租。
- 支持订单后续正常完结或提前终止。
- 支持归还时把资产自动回收到指定门店，形成位置变更记录。
- 暂时不接实名、电子合同、代扣和账单自动生成；续租收费仍由门店或外部平台人工处理。
- 保存订单级续租价格快照、人工调价记录和客户确认凭证，支持存量订单单笔或按条件批量调整。

这套能力本质上是“存量订单跟踪台账”，不是正式租赁订单状态机的替代品。

## 2. 为什么单独建模

外部补录订单不适合直接复用正式 `rental_order`，原因是：

- 它没有平台内首期支付链路。
- 它没有待实名、待签约、待免押、待核销这些平台状态。
- 它当前要求“记录 + 占用资产 + 续租价格台账 + 手动结束”。
- 后续如果第三方正式打通，还可以继续把自动订单和补录订单分开治理。

因此保持独立数据结构：

- V1：`external_rental_order`、`external_rental_order_log`
- V51：`external_order_pricing_revision`

## 3. 适用场景

适用于：

- 门店已经在其他平台成交，现阶段只想补录和跟踪。
- 总部需要把历史在租订单先录入系统。
- 门店需要在系统里手动结束订单、回收资产。
- 总部或门店需要修正已有补录订单的续租整期价、日租价、宽限期或逾期日价。

暂不适用于：

- 平台内实名、签约、代扣闭环。
- 自动生成账单并按期扣款。
- 依赖平台支付流水确认实收；补录订单使用人工填写的实际核销金额参与现有分润台账。
- 小程序用户自己发起的标准租赁下单。

## 4. 角色分工

### 4.1 总部后台

- 查看全量补录订单台账。
- 手动创建补录订单。
- 查看补录订单详情和操作日志。
- 单笔调整续租规则、登记客户确认并查看调价历史。
- 按多种筛选条件预览并批量调整续租规则。
- 对补录订单做正常完结、提前终止。

### 4.2 商户后台

- 仅查看自己授权门店下的补录订单。
- 手动录入自己门店的外部订单。
- 对授权门店的进行中补录订单做单笔或批量续租调价。
- 对进行中的补录订单做完结或提前终止。

### 4.3 用户端

V1 不开放用户端自助创建和自助处理。

## 5. 数据口径

每条补录订单至少记录：

- 来源平台：`DOUYIN / MEITUAN / XIANYU / OFFLINE / OTHER`
- 外部订单号
- 商户、门店
- 门店商品、SKU
- 客户姓名、手机号
- 起租时间、预计归还时间
- 绑定车架资产、绑定电池资产
- 外部租金、签单费、押金
- 实际核销金额和分润快照
- 自动续租开关、整期周期、整期续租价
- 续租计费方式、正常日续租价、逾期日占用费、宽限小时、整期封顶开关
- 调价前后规则、调价原因、状态、批次、操作人和客户确认凭证

补录收益与续租核销口径：

- 首期实际核销金额只作为首期分润基数；后续没有人工修改核销金额时，自动续租使用订单冻结的系统次月续租价。
- 普通资料编辑中修改核销金额，仍作为兼容旧订单的“续租价格时间线”记录带微秒精度的生效时间；它不代表一笔已经实际发生的续租。
- 已实际发生的线下续租统一使用“一次性人工续租”：起点取订单当前预计归还时间，终点取人工选择的精确新到期时间，核销金额为该区间扣费前毛额；该金额不延续到下一周期。
- 一次性人工续租结束后，后续没有新的人工续租时恢复使用订单冻结的系统次月续租价。
- 人工续租和自动续租均先按事件精确起止时间扣除全租期电池成本，再对余额分润；办单费只在首期产生，续租不重复收取。
- 门店实时收益统一为运营分成 + 维修分成 + 办单费净实收，其中办单费按 97% 计入门店，3% 计入平台服务费。
- 历史已锁定的毛额流水和月结金额不直接回写；收益工作台提供97%只读净额口径，月结页面明确区分“新月结97%”与“历史锁定原额”。
- 当前状态：`ACTIVE / COMPLETED / TERMINATED`
- 实际归还门店
- 提前终止原因
- 操作日志

## 6. 关键业务规则

### 6.1 资产占用

创建补录订单时：

- 如果 SKU 要求车架，则必须选择车架资产。
- 如果 SKU 要求电池，则必须选择电池资产。
- 所选资产必须是空闲状态。
- 所选资产不能已被正式订单占用。
- 所选资产不能已被其他进行中的补录订单占用。

创建成功后：

- 资产状态改为 `RENTING`
- 记录资产状态日志
- 如资产当前不在下单门店，自动调拨到该门店并记录位置日志

### 6.2 订单结束

补录订单只支持两种结束方式：

- 正常完结
- 提前终止

结束时：

- 可以指定归还门店
- 可以设置车架归还状态
- 可以设置电池归还状态
- 资产自动回收到归还门店
- 记录资产状态日志和位置日志

### 6.3 跨店归还

V1 已支持在结束补录订单时选择归还门店。

如果订单在 A 门店录入，但实际在 B 门店还车：

- 操作人结束订单时可指定 B 门店
- 系统自动把资产调拨到 B 门店
- 后续库存和位置按 B 门店为准

### 6.4 与正式订单边界

补录订单当前仍不做：

- 平台账单生成
- 自动代扣
- 逾期案件
- 实名签约
- 支付流水
- 分润实收确认

它负责订单台账、资产跟踪、分润核销口径、续租价格台账和人工客户确认，但不执行平台自动收费。

### 6.5 续租价格与批量调价

- 新建补录订单时，从所选门店 SKU 冻结完整续租规则；以后修改 SKU 不反向改变订单。
- V51 升级时，已有补录订单从当前门店 SKU 回填初始续租规则，之后可继续单笔或批量修正。
- 普通补录资料编辑、切换商品或 SKU 不覆盖订单已有续租价格，续租规则只能通过专用调价入口改变。
- 只有 `ACTIVE` 补录订单可以调价；完结或提前终止时自动取消尚未确认的调价。
- 降价、关闭自动续租等有利变更立即生效。
- 涨价、开启自动续租、新增收费、切换计费方式、缩短周期/宽限或取消封顶，需要客户确认。
- 未登记客户确认时生成 `PENDING_CUSTOMER_CONFIRMATION`，订单继续使用原规则；人工登记微信、电话、纸质或其他确认凭证后生效。
- 同一订单已有待确认调价时，不允许再次创建新的调价记录。
- 批量支持勾选订单，或按门店、状态、来源平台、门店商品、SKU、起租时间、预计归还时间、订单号、外部单号、客户、手机号和资产编号组合筛选。
- 批量操作必须先预览，并在执行时提交预览命中数量；命中数量变化则拒绝执行。

### 6.6 一次性人工续租与外卖车电池成本

- 只有进行中的补录订单可以执行人工续租；租期起点固定为操作前订单的 `expectedReturnAt`，人工只填写精确到秒的新到期时间。
- 本次人工核销金额是扣除渠道核销费、平台服务费和电池成本之前的毛额，只覆盖本次事件，不修改标准自动续租规则。
- 电池成本按事件实际持续秒数计算：每满 30 天按月成本，剩余时长按日成本除以 86400 秒折算；30 天仅是电池成本计价阶梯，不用于推导租期。
- 清分顺序固定为“毛额 → 渠道核销费 → 平台服务费 → 全租期电池成本 → 四方分润”。毛额不足以覆盖前三项固定扣减时，整笔人工续租拒绝且不推进到期时间。
- 人工续租事件保存来源、操作账号和必填备注；自动续租标记为系统来源，后续金额核对不会回写人工事件。
- 请求携带操作员打开页面时看到的续租起点；订单锁内发现起点已被其他续租推进时拒绝请求，避免同一毛额被静默套到更短租期。
- 续租起点所属月份已有锁定月结时拒绝直接补记；若该月只有草稿月结，则在人工续租同一事务内重建草稿并纳入本次收益。
- 首期、人工续租和自动续租的电池成本都只扣一次；月结中的电池应付仅作归集展示，不能再次减少门店收益。
- 首期、人工续租和自动续租的毛额都必须覆盖渠道费、平台费和全租期电池成本，否则拒绝生成不平衡的分润快照。
- 上线迁移只增加事件来源与审计字段，历史事件默认标记为系统来源，不自动重算或改写已落库分润和月结。

## 7. 页面规划

### 7.1 总部后台

菜单位置：

- `交易履约 > 外部补录订单`

页面能力：

- 列表
- 状态筛选
- 来源平台筛选
- 门店、门店商品、SKU、起租时间和预计归还时间筛选
- 关键词搜索
- 表格勾选和按当前条件批量调价
- 新建补录单
- 查看详情
- 单笔续租调价、调价历史和人工确认登记
- 正常完结
- 提前终止

### 7.2 商户后台

菜单位置：

- `门店运营 > 外部补录订单`

页面能力：

- 查看当前授权门店补录订单
- 按授权门店筛选并批量调整进行中订单的续租价格
- 新建补录单
- 查看详情
- 正常完结
- 提前终止

- 总部与商户接口已支持单笔调价、调价历史、人工确认、批量预览和批量执行。

- 已验证 V50 旧补录订单升级到 V51 后，可正确回填整期价、日租价、宽限期、封顶和逾期日价。
