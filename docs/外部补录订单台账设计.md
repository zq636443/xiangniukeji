# 外部补录订单台账设计

## 1. 目标

当抖音、美团、闲鱼、线下等业务还没有完全接入平台自动下单链路时，门店和总部需要先把已经真实发生的订单补录进系统，用于完成以下事情：

- 跟踪每一笔外部订单当前在哪个门店、绑定了哪些资产。
- 让资产进入真实的占用状态，避免重复出租。
- 支持订单后续正常完结或提前终止。
- 支持归还时把资产自动回收到指定门店，形成位置变更记录。
- 暂时不接实名、签约、代扣、账单自动生成、分润实收确认。

这套能力本质上是“存量订单跟踪台账”，不是正式租赁订单状态机的替代品。

## 2. 为什么单独建模

外部补录订单不适合直接复用正式 `rental_order`，原因是：

- 它没有平台内首期支付链路。
- 它没有待实名、待签约、待免押、待核销这些平台状态。
- 它当前只要求“记录 + 占用资产 + 手动结束”。
- 后续如果第三方正式打通，还可以继续把自动订单和补录订单分开治理。

因此 V1 单独新增：

- `external_rental_order`
- `external_rental_order_log`

## 3. 适用场景

适用于：

- 门店已经在其他平台成交，现阶段只想补录和跟踪。
- 总部需要把历史在租订单先录入系统。
- 门店需要在系统里手动结束订单、回收资产。

暂不适用于：

- 平台内实名、签约、代扣闭环。
- 自动生成账单并按期扣款。
- 自动分润实收结算。
- 小程序用户自己发起的标准租赁下单。

## 4. 角色分工

### 4.1 总部后台

- 查看全量补录订单台账。
- 手动创建补录订单。
- 查看补录订单详情和操作日志。
- 对补录订单做正常完结、提前终止。

### 4.2 商户后台

- 仅查看自己授权门店下的补录订单。
- 手动录入自己门店的外部订单。
- 对进行中的补录订单做完结或提前终止。

### 4.3 用户端

V1 不开放用户端自助创建和自助处理。

## 5. 数据口径

每条补录订单至少记录：

- 来源平台：`DOUYIN / MEITUAN / XIANYU / OFFLINE / OTHER`
- 外部订单号
- 商户、门店
- 门店商品、套餐
- 客户姓名、手机号
- 起租时间、预计归还时间
- 绑定车架资产、绑定电池资产
- 外部租金、签单费、押金
- 当前状态：`ACTIVE / COMPLETED / TERMINATED`
- 实际归还门店
- 提前终止原因
- 操作日志

## 6. 关键业务规则

### 6.1 资产占用

创建补录订单时：

- 如果 SKU 要求车架，则必须选择车架资产。
- 如果 SKU 要求电池，则必须选择电池资产。
- 所选资产必须是空闲状态。
- 所选资产不能已被正式订单占用。
- 所选资产不能已被其他进行中的补录订单占用。

创建成功后：

- 资产状态改为 `RENTING`
- 记录资产状态日志
- 如资产当前不在下单门店，自动调拨到该门店并记录位置日志

### 6.2 订单结束

补录订单只支持两种结束方式：

- 正常完结
- 提前终止

结束时：

- 可以指定归还门店
- 可以设置车架归还状态
- 可以设置电池归还状态
- 资产自动回收到归还门店
- 记录资产状态日志和位置日志

### 6.3 跨店归还

V1 已支持在结束补录订单时选择归还门店。

如果订单在 A 门店录入，但实际在 B 门店还车：

- 操作人结束订单时可指定 B 门店
- 系统自动把资产调拨到 B 门店
- 后续库存和位置按 B 门店为准

### 6.4 与正式订单边界

补录订单 V1 不做：

- 平台账单生成
- 自动代扣
- 逾期案件
- 实名签约
- 支付流水
- 分润实收确认

它只负责台账和资产跟踪。

## 7. 页面规划

### 7.1 总部后台

菜单位置：

- `交易履约 > 外部补录订单`

页面能力：

- 列表
- 状态筛选
- 来源平台筛选
- 关键词搜索
- 新建补录单
- 查看详情
- 正常完结
- 提前终止

### 7.2 商户后台

菜单位置：

- `门店运营 > 外部补录订单`

页面能力：

- 查看当前授权门店补录订单
- 新建补录单
- 查看详情
- 正常完结
- 提前终止

## 8. 当前已落地能力

截至 2026-07-19，已完成：

- 后端新增外部补录订单主表和日志表。
- 后端新增总部接口与商户接口。
- 后端打通创建、详情、列表、正常完结、提前终止。
- 后端打通资产占用、资产释放、跨店归还自动调拨。
- 后端已支持批量导入补录订单，按“逐行执行、逐行返回结果”的方式返回成功/失败明细。
- 资产详情中的租赁记录已并入补录订单历史，不再只展示平台正式订单。
- 总部后台已新增 `外部补录订单` 页面。
- 商户后台已新增 `外部补录订单` 页面。
- 总部后台与商户后台已新增“批量导入补录订单”入口，支持粘贴多行历史订单文本快速导入。

## 9. 下一步可继续增强

- 支持批量导入历史订单。
- 支持外部平台实收金额对账。
- 支持将补录订单纳入收益、结算、报表口径。
- 支持把补录订单沉淀到资产详情的完整租赁历史视图中。
- 支持和闲鱼/抖音/美团正式链路逐步并轨。
