# 部署说明

第一版建议部署：

- 两个支付宝小程序发布到支付宝小程序平台。
- 总部后台静态资源由 Nginx 托管。
- 后端服务使用 Docker 部署。
- MySQL 使用云数据库 RDS。
- Redis 使用云 Redis。
- 对象存储使用 OSS/COS。
- 支付回调、合同回调、核销回调必须使用 HTTPS 域名。

上线前必须配置：

- MySQL RDS 自动备份，至少保留 7 天，关键上线节点手动创建快照。
- Redis 开启持久化或使用云厂商备份能力。
- 后端健康检查、错误率、接口延迟、扣款失败数、支付回调失败数、对账差异数告警。
- 支付宝账单文件下载、解析和平台对账批次建议由定时任务触发，生产环境需配置支付宝证书、密钥和账单日期调度。
- 导出文件应落到对象存储私有桶，后台只保存带权限控制的下载地址。
