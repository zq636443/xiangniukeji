# 本地开发运行说明

## 后端依赖

后端本地开发依赖 MySQL 和 Redis。当前项目使用独立端口，避免和机器上其他项目冲突：

- MySQL：`localhost:3310`，数据库 `xniu_rental`，账号 `root/root`
- Redis：`localhost:6380`

如果容器已经存在，直接启动：

```bash
docker start xniu-mysql xniu-redis
```

如果是首次创建，可在后端项目目录执行：

```bash
cd /Users/zq/Desktop/享牛科技/server/rental-api
docker compose -f docker-compose.dev.yml up -d
```

## Java 和 Maven

本机已安装：

- JDK 21：`~/.local/devtools/jdk-21`
- Maven 3.9.16：`~/.local/devtools/maven-3.9.16`

若当前终端未加载环境变量，可先执行：

```bash
export JAVA_HOME="$HOME/.local/devtools/jdk-21/Contents/Home"
export PATH="$JAVA_HOME/bin:$HOME/.local/devtools/maven-3.9.16/bin:$PATH"
```

## 后端测试和打包

```bash
cd /Users/zq/Desktop/享牛科技/server/rental-api
mvn test
mvn package
```

测试默认使用 `test` profile，连接 `3310/6380` 这套本地 Docker 依赖。

## 后端本地启动

```bash
cd /Users/zq/Desktop/享牛科技/server/rental-api
SERVER_PORT=8090 \
SPRING_DATASOURCE_URL='jdbc:mysql://localhost:3310/xniu_rental?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai' \
SPRING_DATASOURCE_USERNAME=root \
SPRING_DATASOURCE_PASSWORD=root \
SPRING_DATA_REDIS_HOST=localhost \
SPRING_DATA_REDIS_PORT=6380 \
java -jar target/rental-api-0.1.0.jar
```

说明：

- `application-test.yml` 位于 `src/test/resources`，执行 `java -jar` 时不会打进产物包。
- 因此本地直接启动 jar 时，需要显式传入 `3310 / 6380` 这一套开发环境参数。
- 如果使用 IDE 以 classpath 方式启动，也可以直接挂 `test` profile。

健康检查：

```bash
curl http://localhost:8090/api/health
```

预期返回 `status=UP`。
