# 跨店归还规则

## 场景

用户在 A 门店提车，但到 B 门店归还车辆或电池。

## 业务规则

1. 订单归属门店不变
   - 订单仍归属于创建订单、提车履约的原门店。
   - 后续分润、签单费、订单统计仍按订单原始门店和分润快照计算。

2. 归还门店记录在交接单
   - 商家版小程序结束订单时，需要提交当前操作门店 `returnStoreId`。
   - 归还交接单 `rental_asset_handover.store_id` 记录实际归还门店。

3. 资产自动调拨到归还门店
   - 归还成功后，资产 `asset_item.current_store_id` 自动改为归还门店。
   - 同时写入 `asset_location_history`，备注为“跨店归还自动调拨”。

4. 权限限制
   - 只能在同一个商户旗下跨门店归还。
   - 暂不支持跨商户归还。
   - 操作账号必须有归还门店权限。

5. 资产状态
   - 正常归还：资产状态改为 `IDLE`。
   - 有损坏或异常：可归还为 `PENDING_REPAIR` 或 `EXCEPTION`。
   - 资产状态和位置调拨在同一个事务中完成。
