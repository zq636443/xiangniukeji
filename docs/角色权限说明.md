# 角色权限说明

## 1. 出资方

出资方负责购买车架、电池等资产，并通过名下资产产生租赁收益。

核心权限：
- 查看自己名下资产、资产状态、所在门店
- 查看自己名下资产产生的收益、维保费用、残值
- 查看资产租赁记录和维修记录

限制：
- 不能操作商户、门店、订单履约
- 不能修改资产归属、库存、分润规则

## 2. 运营方

运营方是商户老板。一个商户可以有一个或多个门店，通过车辆和电池租赁订单获取收益。

核心权限：
- 查看自己商户下的门店、订单、资产、分润收益
- 查看门店维修记录和配件消耗情况
- 管理商户下员工账号和授权门店

限制：
- 不能查看其他商户门店数据
- 不能查看其他出资方的全局收益
- 不能做平台级规则配置

## 3. 维修人员

维修人员归属于具体门店，负责在维护车辆或电池时记录维修内容、消耗配件和费用。

核心权限：
- 查看授权门店下的资产
- 查看配件仓库和库存
- 登记维修记录
- 维修时选择消耗配件，系统自动扣减库存

限制：
- 不能查看全平台资产
- 不能查看结算、分润、出资方收益
- 不能操作订单收款、扣款、合同等业务

## 4. 运维人员

运维人员是平台中台角色，负责全局配置、风控、数据审计和异常处理。

核心权限：
- 全局管理商户、门店、员工、出资方、资产
- 管理商品、套餐、门店商品链接
- 管理订单、账单、支付、签约扣款、资金授权
- 查看和处理逾期、核销、实名合同、运维审计
- 管理配件仓库、维修记录、库存流水

限制：
- 平台运维具备最高系统权限，所有敏感操作必须保留审计日志
